# f1macro
f1 macro for buangka

이 문서는 매크로 프로그램인 f1macro에 대한 사용 설명입니다.
프로그램 사용 시 아래의 내용을 모두 숙지하고 동의한 것으로 간주합니다.

## 자동 설정 프로그램은 다음과 같이 사용합니다.

<img src="https://file.notion.com/f/f/9bd45ffc-66ac-8182-98f0-000382468b0b/fed83db4-6e13-495a-967a-12e313b23dd6/image.png?table=block&id=3d145ffc-66ac-8004-8f5f-cdc83696ac76&spaceId=9bd45ffc-66ac-8182-98f0-000382468b0b&expirationTimestamp=1791302400000&signature=pfGDnBGQtbJCfVpdVQTFGonr5Z8BZodUAWhx_43Yw0o&downloadName=image.png" width="400" alt="사용법 이미지">


1. **steam “오프라인 모드”로 게임을 구동한 상태**
2. **메인 화면의 “BRAKING POINT”에 커서가 올라간 상태 (위 사진 참조)**
3. **setting fliter가 expert로 설정되어 있을 것 (기본 설정)**

**위 세가지 조건이 갖춰진 상태로 시작합니다.** 다른 화면에 있다면 직접 메인 화면으로 이동해 커서를 해당 위치로 옮겨주세요.

#### 해당 화면에서 커맨드 (F4 + F5 등)을 입력하면 게임 자동 설정이 시작됩니다.

화면 상단에 메시지가 출력되며 커서와 버튼이 자동으로 눌리며 목표한 설정이 맞춰집니다.

**(중요) 자동으로 설정되고 있는 도중에 다른 버튼을 눌러 커서가 이탈하면 오작동합니다.**
특히 손님분들께서 조이스틱, 1번, 2번 버튼을 누르지 않도록 주의 부탁드립니다. (브레이크, 악셀, 핸들 돌리기는 상관 없음)

자동 설정이 끝나면 마찬가지로 화면 상단에 메시지가 출력되며, 손님분들께 추가적으로 필요한 설정을 직접 하시고 레이스를 시작하시면 됩니다.

프로그램은 윈도우가 켜짐과 동시에 자동적으로 켜져 대기 모드가 됩니다. 따로 프로그램을 끄지 않는 한 다시 실행하실 필요 없습니다.

## 사용 가능한 커맨드 목록

### F4 + F5: LAN GAME 세션 생성(호스트)

자동 세팅을 마치고 어시스트 조정, 팀 설정만 진행하시면 됩니다.

### F4 + F6: LAN GAME 참여

세션 입장, 어시스트 설정, 팀 설정을 진행하시면 됩니다.

### F5 + F6: 싱글 플레이 (F1 WORLD) 그랑프리 생성

마찬가지로 어시스트 조정, 팀 설정만 진행하시면 됩니다.
참고로 팀 설정은 뒤로가기(2번)을 누르시면 됩니다.

### F8: 자동 설정 중지

자동 설정이 오작동하거나 잘못 눌러 매크로를 멈추고 싶을 때 사용합니다.
누르는 즉시 자동 설정이 종료되며 대기 모드로 전환됩니다.
메인 화면으로 직접 이동해 “Braking Point”에 커서를 올리고 다시 시도하시면 됩니다.

### 자동 설정된 세팅값

- Lobby Option: Car category- F1 2026
- Difficulty: 30~35
- Weather of the day : Clear(Dry)
- Track Select: Australia, Bahrain, Canada, Austria, Great Britain, Belgium, Monza, Texas, Mexico, Brazil, Abu Dhabi
- Assists: Beginner - Steering assist Off, Braking assist Medium, ERS assist Off
- Simulation Settings: Race start Assisted

### 📦 설치 및 실행 방법

1. 아래 **Assets** 항목에서 `f1macro_v1.1_dist.zip` (또는 최신 배포 ZIP)을 다운로드합니다.
2. 원하는 폴더에 압축을 해제합니다.
3. **`f1macro.exe`** 아이콘을 클릭하여 실행합니다.

**자동 설정값 수정, 추가 제안 언제든 환영합니다!**

매크로는 완벽하지 않으며, 오작동할 수 있습니다. 오작동 발견 시 제보 부탁드립니다.

이 매크로는 게임 로컬 파일, 메모리를 참조하지 않습니다.
